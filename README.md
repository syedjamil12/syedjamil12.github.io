# EssentialTechGB Ltd — Website

Live site: https://syedjamil12.github.io

A fully static, multi-page business website for EssentialTechGB Ltd — a UK-based refurbished IT equipment reseller. Built as a client project by [ByteGorilla](https://bytegorilla.com).

## Pages
- Home
- Products
- About
- Reviews
- Blog (4 articles)
- Contact (general enquiry + bulk order/quotation form)

## Stack
- Plain HTML5, CSS3, vanilla JavaScript — no build tools or frameworks
- Contact form powered by [FormSubmit](https://formsubmit.co)
- Hosted on GitHub Pages

## Status
Live preview build for client review before final deployment to the client's own hosting.
